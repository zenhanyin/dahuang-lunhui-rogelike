# 大荒轮回录：荒境 HTML 可验证版

单机 Vampire-like RPG 原型，作为《大荒轮回录》世界观下的动作生存分支，用“荒境”区分此前的文游版本。主题是中国神话、轮回成长、多主角命格与大荒叙事探索。

## 运行

直接用浏览器打开 `index.html`。

## 当前版本目标

V0.2.1 验证三件事：

- 敦煌山海残卷风能否落进 HTML/CSS/Canvas。
- 随机地图能否做到有变化但不乱。
- 玩法、音效、伤害飘字和视觉反馈能否形成基础爽感。

## 当前命格

- 轩辕遗剑：飞剑直伤，开局双剑。
- 青丘巫女：符箓追踪 + 幻雾减速。

## 当前玩法

- WASD / 方向键移动。
- 功法自动攻击或自动触发。
- 击杀妖邪掉落妖丹，拾取获得修为。
- 突破境界时三选一强化，包含通用传承和命格专属传承。
- 气血归零后回到命格选择，可重新入荒。

## 配置表

- `src/config.js`：命格、地图、地图变体、事件点、默认武器、敌人数值、升级传承、基础调参。
- `src/game.js`：读取配置表并解释升级效果，处理随机地图、战斗、绘制、音效和伤害飘字。

新增传承和地图优先写成配置项，只有出现新机制时再扩展 `game.js`。

## 地图生成

- 每次入局随机选择地图模板。
- 每张地图再随机抽一个变体。
- 地貌和事件点按 seed 生成。
- 生成时避开出生安全区，并控制摆件/事件点间距。
- 当前地图：荒原试炼、青丘残梦。

当前特征类型：

- 灵脉
- 碎石
- 裂隙
- 幻雾
- 狐火
- 残碑
- 神龛

## 反馈系统

- 临时 Web Audio：发射、命中、拾取、突破、火环、受伤、死亡。
- 音效冷却：避免大量同类命中音同时播放。
- 伤害飘字：飞剑、符箓、丹火、爆裂、受伤使用不同颜色。
- 机制型传承：剑痕三层爆裂、符箓遇幻雾分裂、拾取妖丹震响、精英妖潮夺取丹火。

## 美术方向

- UI：敦煌残卷卡牌风。
- 地图：敦煌纹样化战斗地貌。
- 角色/怪物：敦煌彩绘纸片精灵。
- Boss：敦煌彩绘分层神怪。
- 特效：敦煌纹样化功法光效。
