# V0.3.3a 地图包规范与资源预算

项目：`大荒轮回录：荒境`

目标：把“做一张地图写一套代码”的方式收束成统一地图包流程，同时保证每个出生场景有自己的美术识别度，HTML 运行包保持轻量。

## 核心原则

流程模板化，美术不模板化。

每个场景地图包都必须提供同一组资源类型：

1. `base_tiles`：静态无缝地表 tile。
2. `decals`：贴地痕迹、壁画残线、旧誓纹路等。
3. `props_static`：骨片、草丛、残碑、碎器等静态摆件。
4. `props_animated`：狐火、丹火、灵光等少量循环摆件。
5. `story_markers`：剧情点位三态资源。
6. `events`：可交互剧情物件。
7. `atmosphere`：后续动态空气幻雾层，和地表 decal 分开。
8. `manifest.json`：声明资产、预算、层级和随机权重。

## 运行层级

Canvas 绘制顺序固定为：

1. `base tile layer`：静态、无限拼接、不做独立动画。
2. `decal layer`：贴地痕迹，随地图移动，不单独漂浮。
3. `low props`：低矮地面摆件。
4. 掉落物与弹道。
5. 玩家、怪物、Boss。
6. 高摆件与剧情事件，按世界 `y` 排序。
7. 技能特效、命中特效、飘字。
8. UI。

关键约束：地表痕迹不能像云一样漂；动态空气幻雾只放在 `atmosphere`，不能混到 `decals`。

## 单地图资源预算

| 类型 | 目标数量 | 单项建议体积 | 说明 |
| --- | ---: | ---: | --- |
| base tile | 2-4 | 45-90 KB | 无中心光、无大块切边、四边可拼 |
| decal | 4-8 | 8-45 KB | 用来增加地面细节，优先静态 |
| 静态摆件 | 6-12 | 5-35 KB | 低矮物优先，避免遮挡战斗 |
| 动态摆件 | 1-3 组 | 每组 3-4 帧 | 只给玩法可读或叙事关键物件动画 |
| 剧情点位 | 2-3 组 | 每组 3 态 | 未触发、可触发、已记录 |
| atmosphere | 0-2 | 40-120 KB | 后续专门做，首版可空 |

## 首屏加载预算

- 当前地图包：`<= 1.2 MB`
- 共用 UI/角色/怪物/技能资产：`<= 2.5 MB`
- 首屏总加载目标：`<= 4 MB`
- 手机端预警：`> 3 MB`
- 硬性预警：`> 6 MB`

策略：进入哪个主角，就加载对应出生地图包；不要开局一次性加载青丘、轩辕、神农和章节地图。

## 怪物群与 Boss 承载

怪物群从 V0.3.4 开始系统接入，必须按“当前地图包 + 当前阶段”分包加载。

首屏只加载：

- 当前主角角色。
- 当前出生地图 tile/decal/基础摆件。
- 当前地图小怪 1-2 种。
- 通用 UI。
- 基础技能 VFX。

进局后按阶段懒加载：

- 后续小怪。
- 精英怪。
- Boss 主体和 Boss 专属特效。
- 剧情头像和章节事件资源。
- 高级技能特效。

怪物图集预算：

| 类型 | 帧要求 | 目标体积 | 说明 |
| --- | --- | ---: | --- |
| 普通小怪 | `walk 4` + `hit 1` + `death 3` | 80-180 KB | 每种一个小 WebP 图集 |
| 精英怪 | 普通帧 + `cast/enraged` | 180-300 KB | 入场和技能必须可读 |
| Boss | `idle/walk/tell/attack/hit/death` | 400-800 KB | 主体和尾焰/雾气循环层拆分 |

性能策略：

- 同屏怪多时远处怪物降帧。
- 死亡动画、命中特效、飘字使用对象池。
- 地图 base tile 变化不靠大量 tile 堆数量，主要靠 decal 和摆件。
- Boss 和章节资源不进入首屏常驻包。

## 三主角场景识别

### 青丘

色调：灰紫、墨青、矿物金，古壁画磨损感。  
元素：狐火、旧誓残碑、狐面碎片、残绦、低矮枯草、旧誓线痕。  
禁忌：大块紫雾池、漂浮雾贴图、过亮仙侠光效。

### 轩辕

色调：铁灰、赤褐、暗金、风蚀黄。  
元素：断剑、剑痕、旌旗残片、剑冢石、干草、金属锈迹。  
禁忌：普通战场泥地、现代金属感、单纯黑暗废土。

### 神农

色调：湿青、药绿、丹火橙、土黄。  
元素：草药、丹炉残火、湿地脉络、灵井、根须纹、药灰。  
禁忌：普通沼泽、过绿、过亮、卡通草地。

## 清理规则

不进入可玩包的资源：

- 概念图、定帧图、预览拼图、contact sheet。
- raw AI atlas PNG、抠图中间 PNG、chroma-key 源图。
- 已被正式 tile atlas 替代的旧 v032 单张地图。
- CSS 临时拼出来的 UI 占位图逻辑。

可保留的内容：

- 生成脚本。
- 正式 WebP 运行资源。
- 当前还没替换的公共荒境 `wilderness` fallback。
