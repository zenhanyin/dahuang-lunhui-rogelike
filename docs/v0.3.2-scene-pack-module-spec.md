# V0.3.2 Scene Pack Module Spec

Project: Da Huang Lunhui Lu: Huangjing
Date: 2026-07-24

This spec records the Qingqiu scene pack as the first reusable module pattern. Later Xuanyuan, Shennong, public chapter maps, and boss arenas should follow the same structure so HTML loading stays predictable.

## Layer Rules

1. Static base tile
   - World-space, camera-following, non-animated.
   - Must tile seamlessly on all four edges.
   - Current Qingqiu runtime uses four `qingqiu_base_final_*` same-edge variants.
   - Multiple base tiles cannot be randomly mixed unless they share verified edge rules.

2. Ground decal
   - World-space, static, small WebP.
   - Used for old vow traces, teal mineral veins, pale gold mural lines, cracks, and stains.
   - Decals create variation; base tiles should not carry large obvious focal shapes.

3. Static prop
   - World-space, non-animated.
   - Used for grass, shards, ribbons, bones, broken objects, and other low-cost dressing.

4. Animated prop
   - World-space, animated by small frame loops.
   - Recommended 3-4 frames per loop.
   - Used for foxfire, spirit flames, ritual lights, and later atmosphere anchors.

5. Story event point
   - World-space, interactive.
   - Must have idle, ready, and done art states.
   - Should not rely on floating text, arrows, debug circles, or prototype rings.

6. Dynamic atmosphere
   - Optional, screen/world overlay.
   - Must be separate from ground decals.
   - Can be disabled or reduced on mobile.

7. Combat and VFX
   - Drawn above world props and below UI.
   - Must be object-pooled and capped.

8. UI
   - Screen-space only.
   - Never use UI ornament as a world tile or world prop.

## Current Qingqiu Gaps

- The first final Qingqiu base pass is seamless and stylistically closer, but still shows some same-source repetition at wide zoom.
- Next expansion should use real Wang-tile rules or more hand-authored same-edge interiors instead of random unrelated tile mixing.
- Foxfire and old vow stele are readable, but need a stronger second art pass for final production.
- Formal skill icons now use small medallion WebP files, but later should be replaced by hand-authored atlas icons.

## HTML Budget

- One loaded scene pack target: 2-5 MB desktop, 1.5-3 MB mobile first pass.
- Base tile: 1 safe runtime tile plus optional locked candidates.
- Decals: 6-12 small WebP files.
- Static props: 10-20 small WebP files.
- Animated props: 3-6 groups, each 3-4 frames.
- Story event points: 3-5 types, each idle/ready/done.
- Boss assets are delayed until chapter progress needs them.

## Acceptance

- No visible rectangular seam during 2 minutes of movement.
- With HUD hidden, the scene still reads as the target location.
- Event points are readable before interaction and clearly change when ready/done.
- No prototype arrow, debug circle, placeholder ring, or plain geometric marker appears in the scene pack.
- Runtime test must pass desktop visual QA and stress probe before copying the pattern to the next scene pack.
