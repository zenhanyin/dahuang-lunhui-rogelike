Date: 2026-08-02

## Scope

This pass closes the current Xuanyuan map sample into a stable runtime template, while keeping Qingqiu as the accepted reference scene pack.

The goal is not to finish all Xuanyuan art forever. The goal is to stop the unstable prototype/CSS-looking assets from re-entering runtime, verify seamless map behavior, and define the next asset pass clearly.

- Ready event feedback is now handled by the formal event disk plus a small proximity prompt.
- Xuanyuan map manifest and the global asset manifest were updated to describe the current runtime state.

## Acceptance Notes

Xuanyuan now matches the confirmed direction better than the previous dirty/prototype map:

- top-down ground, not pseudo-3D;
- Dunhuang mineral fresco palette;
- cracked ochre-gray earth;
- low-relief cloud and sword engravings;
- no obvious green-screen edge pollution in the active runtime props.

Remaining gap:

- the Xuanyuan base tile is stable, but still needs more low-frequency variation;
- the low-ground props are runtime-safe, but still less art-rich than the confirmed keyframe;
- event point density and visual priority need another polish pass;
- Qingqiu remains the stronger scene sample and should be used as the comparison target.
