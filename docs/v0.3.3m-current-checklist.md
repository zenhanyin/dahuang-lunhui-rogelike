## P0: First Chapter Playable Spine

Goal: build one complete 6-8 minute run that feels like a narrative survivor game.

Required sequence:

1. Start as Xuanyuan or Qingqiu.
2. Early enemy pressure.
3. First upgrade card choice.
4. First story point appears and can be triggered.
5. First elite wave.
6. Second story point advances the main clue.
7. Boss warning appears.
8. Chapter Boss enters.
9. Player dies or clears the chapter.
10. Reincarnation summary records what changed.

Acceptance:

- The player knows there is a main story.
- The player sees that story points are part of the run, not decoration.
- Death/clear gives new memory or clue feedback.
- The run has an obvious middle and end, not endless wandering.
