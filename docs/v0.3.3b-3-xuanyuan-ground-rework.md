# V0.3.3b-3 Xuanyuan Top-Down Ground Rework

Goal: rebuild the Xuanyuan map art direction against the Qingqiu asset logic, not against the rejected program-looking placeholder pack.

## Locked Direction

- Pure top-down, ground-first composition.
- Dunhuang mineral fresco style: cracked earth, muted cinnabar, oxidized bronze green, dusty gold linework, old ochre.
- No pseudo-3D ruins, no tall props, no floating UI-like markers.
- Xuanyuan identity comes from sword-line engravings, bronze corrosion, oath cracks, chariot-track traces, and flat sword-array seals.

- `xuanyuan_topdown_base_keyframe.png`

- `xuanyuan_ground_decal_sheet.png`

## Comparison To Qingqiu

Qingqiu works because it has:

- base terrain for mood
- grounded decals for memory
- theme props for identity
- event markers that belong to the map theme

Xuanyuan should mirror that structure:

- base terrain: sword-mark mineral earth
- decals: bronze oxidation, sword-array lines, chariot tracks, oath cracks
- props: broken swords, bronze sword guards, armor plates, low altar slabs
- events: grounded sword seal, cracked oath slab, sword-array core

## Rejected From Current Xuanyuan Runtime Pack

These motifs should not enter the formal Xuanyuan map pack:

- generic bones
- cheap upright red flags
- cone-like sword placeholders
- floating circular story badges
- gray empty terrain with sparse random props
