# V0.3 正式美术资产缺口清单

项目：《大荒轮回录：荒境》

记录时间：2026-07-22

本清单用于记录 V0.3.1 之后仍缺的正式美术、动效、音频和叙事资产。目标是让 HTML 单机版本在低内存、低解码压力下逐步替换原型资源。

## 角色与怪物

### 普通小怪

- 需要更多普通小怪，并且必须带行走图。
- 第一批建议补 4 类：荒魂、狐火侍、石皮残兵、腐草妖。
- 每类至少左右向 3-4 帧，优先保证同屏数量下的 WebP 体积。
- 用途：丰富敌潮层次，避免玩家一直打同一种小怪。

### 精英怪

- 需要更多精英怪，并且必须带行走图。
- 第一批建议补 3 类：赤焰精英、碑灵精英、雾影精英。
- 精英需要更明显的轮廓、血条颜色、入场提示和受击反馈。
- 用途：形成 60-90 秒一次的小阶段压力。

### Boss

- Boss 战需要独立资产，并且必须带动作帧。
- 第一章建议先做“青丘魇母”或“旧誓碑灵”二选一。
- 最小动作帧：idle 4 帧、移动/漂浮 4 帧、攻击前摇 2 帧、攻击释放 3 帧、受击 1 帧、死亡/退场 4 帧。
- Boss 还需要专属血条、登场警示、章节场景、专属音乐层和技能特效。

## 技能、动特与反馈

### 技能动特

- 飞剑：剑气拖尾、命中爆光、剑痕叠层、剑阵升级形态。
- 飞符：符纸飞行、符咒锁敌、冰裂/雷纹/爆符分支。
- 幻雾：范围边界、减速层、狐影残像、雾中敌人状态提示。
- 丹火：地面火印、爆燃、灼烧持续、拾取触发小爆。
- 神通/冲刺：蓄力环、释放冲击、残影、短暂无敌提示。

### 场景摆件动效

- 需要更多有动效的场景摆件。
- 第一批建议：灵火、狐火、灵井、荒祠、残碑、赤裂、梦雾池、风化经幡。
- 摆件分普通装饰和剧情点位两套视觉状态：普通、可触发、已完成。
- 事件摆件要比普通摆件更明确，玩家靠近前就能看出“这里有事”。

### 美术字与数值反馈

- 伤害飘字需要碑拓/朱砂/石绿墨迹风格。
- 暴击、回血、护盾、构筑触发、剧情获得线索都应有不同字形或颜色。
- 资源获得/消耗需要飞向 UI 的动效，尤其是灵髓和丹火。

## 地图与章节场景

### 无限延展地图

- 需要正式的可无限延展地图场景。
- 当前 runtime 地图不是完全原型，但仍被程序化底图、纹理和摆件拉回原型感。
- 下一步需要正式章节地图包：低频大地貌底图、可重复边缘过渡块、小型随机摆件、事件点位资产。
- 每章至少需要：基础地面 2-3 套、边缘过渡 4 向、叙事点位 5 类、Boss 场景专用底图 1 套。

### 章节化叙事场景

- 优先级建议放在 V0.3.3，但它依赖 V0.3.2 的场景资产。
- 剧情点位要和地图变化绑定：残碑、狐火、荒祠、灵井、赤裂分别对应不同短剧情和奖励/代价。
- 轮回推进后，地图应出现轻量变化：旧碑增多、雾色变化、Boss 前兆、已解锁线索标记。

## UI 与叙事界面

### 正式 UI 装饰件

- V0.3.1 已有九宫格底层，但还缺定帧图里的独立装饰。
- 需要补：卷轴轴头、莲纹题头、飞天飘带、角色挂饰、边角铜扣、按钮高亮层。
- 这些应作为小 WebP 叠层，不再用整张大图硬贴。

### 卡牌构筑 UI

- 升级卡牌需要流派标识、稀有度、消耗/免费状态、选择后领悟动效。
- 当局构筑需要专门入口：当前流派、已选卡牌、共鸣进度、剧情印记。
- 暂停里的构筑记录只是第一版，需要做成“构筑札记”正式面板。

### 剧情 UI

- 剧情点位对话框需要标题、地点/人物名、短正文、选择按钮、奖励/代价提示。
- 剧情故事/命簿界面需要记录本局线索、轮回记忆、章节推进。
- 结算界面需要体现“本世经历”和“轮回留下了什么”，不能只显示生存时间和击杀。

## 音乐音效

- 需要正式音频资源。
- BGM：探索层、敌潮增强层、Boss 层、剧情点位低压层。
- SFX：命中、击杀、拾取、升级、选卡、略过、刷新、锁定、剧情触发、神通、Boss 登场。
- 音效要和机制绑定，避免只是背景装饰。

## 工程与性能

### 资产预算与加载策略

- 普通怪和精英怪按当前章节加载，不全部常驻。
- Boss 资产延迟加载，只在章节线索接近完成或 Boss 战前加载。
- 场景摆件和 UI 装饰优先 WebP 小件，避免 2048 大图常驻。

### 移动端专项资产

- 竖屏 HUD、竖屏升级卡、竖屏剧情事件、触控摇杆、神通按钮需要单独验证。
- 不直接缩放横屏 UI，否则文字和触控区会很快失控。

## 建议优先级

- V0.3.2：正式无限地图场景包 + 场景摆件第一批 + 剧情点位视觉重做。
- V0.3.3：章节化叙事 + 剧情事件 + 轮回记忆 + Boss 触发条件。
- V0.3.4：小怪/精英怪扩充 + 第一章 Boss 战资产与逻辑。
- V0.3.5：技能动特、飘字、美术字、音乐音效爽感补完。
- V0.3.6：竖屏移动端 UI 与操作专项验证。
