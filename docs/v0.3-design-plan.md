# V0.3 《大荒轮回录：荒境》大荒叙事构筑版规范

## 版本定位

V0.3 的目标不是继续堆怪或堆数值，而是验证《大荒轮回录：荒境》的项目差异化：

> 古朴厚重敦煌矿物壁画风 + 吸血鬼Like生存循环 + 功法构筑 + 剧情点位 + 轮回叙事。

玩家进入一局后，应感受到自己不是在普通刷怪场里升级，而是在一世轮回中探索大荒遗痕、拼回前世记忆，并用功法构筑支撑生存。

## 美术风格定义

核心风格为“古朴厚重的敦煌矿物壁画风”。

关键词：

- 古朴、厚重、壁画、矿物颜料、残卷、碑拓、经页。
- 石青、石绿、赭石、朱砂、藤黄、老墙灰。
- 低饱和整体色调，局部用紫雾、灵火、丹火做神异高亮。
- 云气线描、莲纹、飞天飘带、残损边缘、壁画颗粒与剥落感。

明确避免：

- 轻飘浅色国风。
- 暗黑仙侠、黑金金属 UI。
- 赛博霓虹、大面积高亮发光。
- 过度干净的现代卡片、网页按钮和手游金属框。

判断标准：

- 太亮会像轻国风。
- 太黑会像暗黑仙侠。
- 太金属会像修仙手游。
- 太干净会不像壁画。
- 正确方向应是石青赭色压住底色，朱砂与石绿点睛，UI 像残卷和经页从壁画里长出来。

## 音乐音效规划

音乐目标：

- 不做明亮仙侠，不做电子暗黑。
- 主基调是低沉、古朴、空旷的大荒感。
- 使用鼓、埙、箫、低弦、磬、铃、木鱼类音色构成层次。
- 战斗音乐不必一直高燃，应随敌潮和 Boss 逐步加压。

音乐分层：

- 常态探索：低鼓点、风声、远箫、轻微经卷摩擦感。
- 敌潮增强：加入更密的鼓、低弦和不稳定打击。
- 升级选卡：短暂停顿，进入清亮但不轻飘的“悟道”音色。
- 剧情点位：环境声压低，加入残响、石碑震动、低语感。
- Boss：鼓点加重，加入铜钹、低吼、丹火爆裂层。

音效清单：

- 命中：短促、有材质感，剑气、符咒、丹火分别区分。
- 击杀：轻爆裂或魂火散开，不能只有数字消失。
- 拾取：灵珠吸附有连续上扬音，强化“资源进账”感。
- 升级：明确的顿挫与光声，提示局内节奏变化。
- 选卡：纸页、铜铃、法印落定三层反馈。
- 略过：卷页收起，灵髓入账音。
- 剧情点位：石碑/井水/祠香/狐火/赤裂各有专属触发声。
- 神通：低频蓄力、释放爆发、余响收束。

## 动特规划

动效目标：

- 用机制动效替代强数值膨胀，爽感来自“看得懂的连锁变化”。
- 动效要有敦煌壁画的线描、飞天飘带、矿物颗粒和残卷光边。
- 避免现代霓虹粒子、纯黑金爆闪、手游式夸张金属光。

基础动特：

- 剑气：石青白光刃，带残卷飞白轨迹和剑痕停留。
- 符咒：朱砂符纸飞行，命中后印章式展开。
- 幻雾：紫雾边缘低亮，内部有青丘线纹游动。
- 丹火：朱砂橙火芯，外圈带烟熏颗粒。
- 拾取：灵珠被吸入玩家，路径有短暂青绿尾迹。
- 伤害飘字：美术字应像碑拓/朱砂/石绿墨迹，不使用默认粗体网页字。

高级动特：

- 连锁：目标之间出现符线或剑痕牵引。
- 爆裂：先有法印压缩，再有壁画颗粒向外剥落。
- 控场：地面出现圆形莲纹/云纹法阵，边缘轻旋。
- 神通：屏幕短暂压暗，法印扩大，随后释放主特效。
- 剧情点位：靠近时低亮呼吸，触发时残字或水纹浮现。

### UI 动特规划

UI 动特目标不是单纯炫技，而是让玩家明确感知“获得、消耗、触发、构筑变化和剧情推进”。

资源反馈：

- 灵髓增加：青绿色魂火从拾取点、卡牌或事件结果飞向右上资源牌。
- 灵髓消耗：资源牌边缘出现短暂石绿裂纹，数字闪动后扣减。
- 丹火增加：朱砂火点飞入右上资源牌，伴随短暂热浪扭曲。
- 丹火消耗：资源牌轻微暗下，出现朱砂余烬散落。

选卡反馈：

- 进入选卡：战斗画面被壁画烟尘轻压，标题牌匾卷起展开。
- 卡牌入场：三张卡依次落下，间隔 80-120ms。
- 选中卡牌：石青/朱砂描边亮起，图标圆章闪一次。
- 领悟完成：卡牌化成墨线或法印流向角色，角色脚下出现对应功法纹样。
- 略过悟道：卡牌向两侧收卷，一枚灵髓飞向右上资源牌。

剧情点位反馈：

- 靠近点位：残碑/荒祠/灵井/狐火周围出现低频呼吸光。
- 可触发提示：地面浮出很淡的莲纹或云纹圈，不弹大按钮遮挡战斗。
- 触发剧情：碑拓字或水纹先浮现，再展开对话卷轴。
- 事件结果：祝福走石绿光流，诅咒走朱砂裂纹，章节线索飞入命簿。

神通反馈：

- 充能：圆章外圈以莲纹/云纹逐格点亮，不使用普通现代 CD 环。
- 可用：按钮内图案呼吸一次，不持续闪烁。
- 释放：按钮下压，法印从按钮扩散到角色脚下，再释放主特效。
- 冷却：按钮变低饱和灰青，云纹重新缓慢回充。

暂停反馈：

- 战斗态暂停按钮不使用现代 `Ⅱ` 符号，改用“暂”或“止”印章。
- 点击暂停时像盖章一样轻压，随后命簿/卷轴铺开。
- 暂停态主按钮使用横向“继续”残卷牌，不使用圆形法印。
- 继续时卷轴向两边收起，战斗从壁画静止状态恢复流动。

飘字反馈：

- 普通伤害：石灰/淡朱砂碑拓字，上浮后碎成粉尘。
- 暴击或机制伤害：朱砂大字，附带小印记，如“裂”“焚”“缚”。
- 幻雾伤害：紫青墨迹字。
- 回血：石绿字，从角色脚下向上浮。

低内存实现原则：

- 优先用 CSS transform、opacity、filter 做 UI 入场和按钮状态。
- Canvas 粒子优先用少量点、线、圆和小图标，不用大序列帧。
- 资源飞入使用小 WebP 图标或 Canvas 轻粒子。
- UI 背景使用 9-slice 友好的小 WebP，不直接加载整张概念图。
- 选卡、剧情、暂停、结算弹层只在触发时创建/显示，结束后隐藏或销毁。

V0.3.0 最小 UI 动特集：

- 资源飞入。
- 选卡展开/收卷。
- 卡牌选中飞向角色。
- 神通充能/释放。
- 剧情点位呼吸光。
- 美术字飘字。

## 技能机制规划

构筑应围绕“功法 + 机缘 + 剧情印记”展开。

功法线：

- 剑气诀：直线穿透、剑痕留场、剑阵爆发。
- 玄冰咒：减速、冻结、碎冰溅射。
- 离火术：灼烧、范围爆裂、丹火余烬。
- 幻雾步：闪避、幻影、迷雾减速。
- 摄魂符：追踪、牵引、连锁标记。

机缘线：

- 血玉护命：拾取妖丹或灵珠时少量回血。
- 青风诀：移速提升，降低被围死概率。
- 女娲息壤：受伤后护盾或回血。
- 灵井回照：低血量触发一次净化/回血。
- 拾遗入怀：扩大拾取范围，提升节奏顺滑度。

剧情印记：

- 残碑印记：解锁前世功法变体。
- 青丘印记：提升幻雾、分身、闪避相关卡出现率。
- 赤裂印记：丹火更强，但敌潮更危险。
- 荒祠印记：祝福与诅咒并存，改变一局节奏。
- 轮回印记：结算后保留轻量解锁。

神通机制：

- 每个角色只保留一个主动神通。
- 神通按钮不是技能组入口，而是保命/爆发/清场的低频决策。
- 神通充能来源应清楚：击杀、拾取、受伤边缘、剧情点位奖励。

## 爽感规划

V0.3 不追求强数值碾压，爽感来自四层。

第一层：即时反馈。

- 命中有声音、闪光、受击动作、飘字。
- 击杀有魂火散开、资源掉落、短促音效。
- 拾取有吸附轨迹和资源 UI 跳动。

第二层：机制成型。

- 玩家拿到卡后应立刻看见行为变化。
- 例如剑气从单发变穿透，符咒从单体变连锁，幻雾从移动变范围控场。
- 卡牌描述必须写机制结果，不只写数值。

第三层：局内节奏。

- 升级选卡打断战斗，形成“压力释放”。
- 剧情点位提供“探索发现”。
- Boss 出现形成阶段目标。

第四层：轮回叙事。

- 死亡不是失败黑屏，而是获得本世记录。
- 结算要显示本局触发的记忆、击杀、线索、功法成型。
- 下一局开局要让玩家感到上一世留下了痕迹。

爽感验证问题：

- 玩家是否能听出命中、击杀、拾取、升级的区别？
- 玩家是否能看出某张卡让技能发生了变化？
- 玩家是否知道灵髓和丹火有什么用？
- 玩家是否知道剧情点位推动了章节？
- 一张静态截图是否已经能传达敦煌厚重感？

## 核心玩法循环

V0.3 局内循环：

1. 选择命格开局。
2. 在随机大荒场景中走位生存。
3. 自动功法攻击敌潮。
4. 拾取修为升级。
5. 升级免费三选一，形成局内构筑。
6. 探索剧情点位，获得线索、事件、资源或风险。
7. 收集章节线索后触发章节 Boss。
8. 死亡或通关后进入轮回结算。
9. 轮回记忆影响下一局开局、卡池或剧情点位。

## 玩法逻辑规划

V0.3 的玩法目标是先把“吸血鬼Like基础闭环 + 大荒叙事探索”跑通，而不是急着堆系统。

局内基础逻辑：

- 玩家只需要控制移动、拾取、避险和少量主动神通。
- 普通功法自动释放，避免做成动作 RPG 技能栏。
- 升级时暂停战斗，免费三选一领悟功法或机缘。
- 可以略过本次领悟，获得少量灵髓补偿。
- 敌潮按时间、章节线索、剧情事件逐步增强。
- 地图应支持跨屏连续移动，而不是固定一屏战斗。

资源逻辑：

- 修为：经验值，用于升级触发三选一。
- 灵髓：局内策略资源，用于刷新、事件代价、商店或略过补偿。
- 丹火：稀有资源，用于重铸、复活、锁定高阶选项或特殊剧情。
- 章节线索：推动 Boss 和剧情，不直接等同于战力。

地图逻辑：

- 基础地形无限延展，玩家跨屏移动时持续生成新区域。
- 场景摆件按章节主题和剧情点位权重生成。
- 剧情点位有冷却与密度控制，避免走几步就弹窗。
- 章节场景应随剧情推进改变氛围、怪物和点位池。

差异化逻辑：

- 其他吸血鬼Like主要靠武器叠加、怪潮压力和数值成长。
- 《大荒轮回录：荒境》要额外让玩家感到“这一局在推进一段大荒往事”。
- 因此每局至少应出现可感知的剧情点位、记忆碎片或章节线索变化。

## 吸血鬼Like 基础约束

必须保留：

- 自动攻击。
- 玩家主要操作为移动与少量主动动作。
- 拾取经验并升级。
- 升级免费三选一。
- 敌潮压力随时间增强。
- 武器/被动/机制逐渐成型。
- 局内死亡或通关后结算。

不应使用：

- 升级卡牌需要花局内货币购买。
- 常驻大技能栏误导玩家点击自动技能。
- 强数值永久养成压过局内构筑。

## UI 信息架构

局内 UI 固定为五个区域。

### 左上：角色状态 HUD

显示：

- 游戏名或轮回命簿标识。
- 当前命格/角色。
- 气血。
- 修为经验。
- 境界。
- 轮回时间。
- 斩妖数。

美术形态：

- 残卷、经页、飞天装饰。
- 浅羊皮纸、烟熏赭色、朱砂印章、石绿边饰。

### 右上：资源与系统

显示：

- 灵髓。
- 丹火。
- 暂停按钮。

资源语义：

- 灵髓：刷新选项、略过补偿、剧情事件、局内商店。
- 丹火：稀有重铸、锁定、复活、特殊事件。

### 右下：神通/大招

保留一个主动按钮。

语义：

- 普通功法自动释放。
- 冲刺/神通/大招属于少量主动操作。
- PC 可用快捷键，手机右下触控。

美术形态：

- 法印、铜镜、莲纹圆盘。
- 不与自动技能混成一排。

### 边缘：轻量构筑摘要

战斗中只显示小型构筑摘要，不做大技能栏。

可显示：

- 已拥有功法小图标。
- 等级珠。
- 进化提示小标记。

禁止：

- 底部常驻一排大技能按钮。
- 自动技能看起来像可以手动点击。

### 中央弹层：选择/剧情/暂停

中央弹层只在需要决策时出现：

- 升级构筑三选一。
- 剧情点位对话。
- 随机事件选择。
- 暂停/设置。
- 轮回结算。

## Build 构筑系统

构筑不靠底部技能栏表达，而靠升级卡牌、暂停面板、结算面板表达。

构筑类型：

- 主功法：主要输出，如剑气诀。
- 辅功法：控制、追踪、范围，如玄冰咒、幻雾步。
- 生存机缘：回血、护盾、拾取范围、移速。
- 机制变体：剑痕爆裂、符咒分裂、丹云余烬。
- 剧情印记：剧情点位带来的局内改变。
- 轮回记忆：跨局解锁或提示。

升级卡牌规则：

- 升级免费三选一。
- 每张卡应明确说明机制变化。
- 可以略过悟道，获得少量灵髓。
- 灵髓用于刷新/事件/商店，不用于购买普通升级卡。

卡牌分类建议：

- 功法强化：数量、范围、冷却、穿透。
- 机制变化：爆裂、分裂、连锁、控场。
- 生存机缘：回血、护盾、拾取、移速。
- 剧情印记：由剧情点位或章节线索解锁。

## 神通/大招机制

神通是“进化版吸血鬼Like”的主动爆发层，不是传统技能栏。

设计原则：

- 每个角色一个命格神通。
- 能量来自击杀、拾取、剧情点位或受伤边缘。
- 冷却和充能需要清晰可见。
- 神通要有强美术反馈，但频率低。

示例：

- 轩辕遗剑：不周剑阵，短时间剑气爆发并触发剑痕。
- 青丘巫女：九尾幻界，大范围幻雾、减速、分身。
- 神农丹徒：百草丹火，灼烧敌群并回血。
- 轮回通用：轮回一瞬，短暂停滞或清场救命。

## 剧情点位系统

剧情点位是区别普通吸血鬼Like的核心系统。

点位不是普通摆件，必须有：

- 地图视觉符号。
- 触发范围和提示。
- 剧情文本。
- 选择或领取动作。
- 玩法后果。
- 章节线索作用。

### 五类基础点位

残碑：

- 视觉：半埋石碑，朱砂残字，暗金裂纹。
- 文案：前世记忆、章节主线。
- 玩法：获得线索、解锁卡池、提示 Boss。
- 章节：主要线索来源。

灵井：

- 视觉：石绿圆井，水面倒影，低亮灵光。
- 文案：轮回倒影、另一世的自己。
- 玩法：回血、灵髓、净化负面。
- 章节：可能出现 Boss 弱点。

荒祠：

- 视觉：破败小祠，残香、供牌、莲纹。
- 文案：古神、供奉、代价。
- 玩法：祝福/诅咒二选一。
- 章节：解锁神明相关故事。

狐火：

- 视觉：青绿狐火，紫雾边缘，青丘符纹。
- 文案：青丘旧约、幻雾术法。

- 章节：青丘线索。

赤裂：

- 视觉：朱砂裂谷，丹火污染，黑红边缘。
- 文案：不死药污染、昆仑丹方。
- 玩法：高风险战斗事件，奖励丹火。
- 章节：污染线索。

## 轮回机制

轮回机制把“死亡重开”升级成“多世推进”。

轮回保留：

- 章节线索。
- 记忆碎片。
- 图鉴条目。
- 解锁卡牌。
- 解锁命格。
- 少量轮回点。

轮回不应变成强数值永久养成。

V0.3 最小闭环：

1. 局内触发剧情点位。
2. 获得记忆碎片或章节线索。
3. 死亡/通关后结算显示本世经历。
4. 获得轮回点。
5. 下一局开局显示已记起的线索。
6. 解锁一张卡、一类点位或一个命格提示。

## 地图与章节场景

地图分三层。

### 随机场景层

服务基础刷怪与探索。

候选：

- 荒原残梦。
- 青丘幻雾。
- 赤裂古道。
- 灵井荒台。
- 残碑沙原。

要求：

- 可以随机生成。
- 中心可走位区域清晰。
- 地图摆件不遮挡玩家判断。
- 场景变化和剧情点位绑定。

### 剧情节点层

点位必须比普通摆件更有辨识度。

要求：

- 可远看识别类别。
- 靠近有轻提示。
- 触发后不频繁打断战斗。
- 与章节线索或局内机制有关。

### 章节场景层

用于 Boss 或章节推进。

候选：

- 第一章：青丘梦渊。
- 第二章：赤裂荒原。
- 第三章：不周断剑。
- 第四章：神农丹火。
- 第五章：昆仑药庭。

章节场景要比随机场景主题更强。
