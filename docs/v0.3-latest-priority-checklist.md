# V0.3 最新开发清单与优先级

项目：《大荒轮回录：荒境》

记录时间：2026-07-22

本清单用于统一后续开发方向。V0.3 的目标不是只做一个“自动攻击刷怪原型”，而是做一个带 RPG 叙事节奏的东方神话吸血鬼like。

## 核心定位

保留吸血鬼like的必要骨架：

- 升级
- 构筑
- 怪潮
- 精英
- Boss
- 局外成长

我们的玩法差异放在：

- 大荒剧情点位
- 轮回记忆
- 功法进化
- 章节 Boss

最终体验目标：

- 玩家第一眼能理解这是吸血鬼like。
- 玩 3-5 分钟后能感到这是有主线、有轮回、有章节推进的 RPG。
- 叙事不是纯碎片化文本，而是线性主线有明确节奏，玩家能逐步知道结局。
- 轮回用于补充碎片、解锁分支、理解因果，并最终通向真结局。

## 当前实际状态

### 已具备

- HTML Canvas 单机可运行。
- 多角色开局。
- 自动攻击、刷怪、拾取、升级三选一。
- 基础怪潮与死亡结算。
- 随机地图与跨屏移动。
- 初步剧情点位。
- 初步构筑记录。
- 初步资源：灵髓、丹火。
- V0.3.1 九宫格 UI 底层已接入。
- Runtime WebP 资产已建立，资源体积目前可控。

### 仍不足

- 场景地图仍偏原型感，正式地图美术不成立。
- 主 UI 只是九宫格底层，不够贴近定帧图。
- 构筑系统还没有强目标和进化链。
- 怪潮没有明确阶段表。
- 精英怪没有清楚职责和奖励。
- Boss 战只有规划，没有局内战斗闭环。
- 剧情点位能触发，但缺主线节奏、选择后果和轮回影响。
- 局外成长还没有形成正式系统。
- 音乐音效、动特、飘字仍是验证级。
- 竖屏移动端只是适配雏形。

## 必须补齐的吸血鬼like骨架

### 1. 升级

当前已有升级三选一，但还需要：

- 经验需求曲线。
- 升级反馈。
- 升级后技能变强的可视化。
- 卡牌稀有度。
- 刷新、跳过、锁定的资源消耗感知。

### 2. 构筑

当前只有构筑摘要，还需要：

- 功法流派标签：剑气、符咒、幻雾、丹火、生存、机缘。
- 当局构筑查看界面。
- 卡牌之间的组合关系。
- 功法进化链。
- 构筑选择后的动效与音效反馈。

### 3. 怪潮

当前有刷怪，但缺阶段设计。需要：

- 时间轴怪潮表。
- 普通潮、夹击潮、精英潮、事件潮。
- 怪物职责分工：近战压迫、远程骚扰、冲锋封路、召唤强化、地面污染。
- 怪潮和剧情点位/Boss 前兆联动。

### 4. 精英

当前精英存在感不足。需要：

- 明确精英类型。
- 精英入场提示。
- 精英独特技能。
- 精英奖励：丹火、残卷、高阶机缘、宝箱/古匣。

### 5. Boss

Boss 应是章节目标，不只是大怪。需要：

- Boss 触发条件：时间、章节线索、剧情事件、轮回层数。
- Boss 阶段：登场、压迫、转阶段、狂暴、退场。
- Boss 技能池：范围预警、追踪弹幕、地面污染、召唤小怪。
- Boss 奖励：剧情线索、特殊卡池、轮回印记、丹火。
- Boss UI：血条、警示、阶段提示、压迫音效。

### 6. 局外成长

我们不做强数值堆叠，但必须有轮回成长。需要：

- 轮回记忆。
- 命簿条目。
- 主角/命格解锁。
- 卡池解锁。
- 剧情线索保留。
- 真结局条件推进。

## 我们的差异化系统

### 大荒剧情点位

剧情点位是局内探索核心，不是普通随机弹窗。

需要：

- 地图上明显可识别的点位资产。
- 靠近提示。
- 触发对话。
- 选择奖励/代价。
- 影响当局构筑、资源、怪潮或章节线索。

第一批点位：

- 残碑：主线线索、旧世记忆。
- 狐火：青丘剧情、幻雾/狐系功法。
- 荒祠：献祭、祝福、诅咒。
- 灵井：恢复、资源、随机风险。
- 赤裂：Boss 前兆、危险事件、高价值奖励。

### 轮回记忆

死亡不是失败，而是推进故事。

需要：

- 本局经历记录。
- 获得线索记录。
- 解锁新卡、新角色、新剧情点。
- 下一局出现变化。
- 轮回多次后补足碎片，理解主线真相。

### 功法进化

功法进化是构筑爽感核心。

示例链：

- 剑气诀 + 不周剑痕 + 后羿残弦 = 不周剑阵。
- 玄冰咒 + 飞符分裂 + 碑灵印 = 寒碑符雨。
- 幻雾步 + 青丘幻身 + 狐火旧约 = 青丘迷梦阵。
- 离火术 + 丹火残种 + 妖丹震响 = 丹火焚野。
- 甘露回生 + 女娲息壤 + 神农残卷 = 生生不息。

### 章节 Boss

章节 Boss 承担主线推进。

第一章建议：

- 章节：青丘残梦。
- Boss 候选：青丘魇母 / 旧誓碑灵。
- 触发方式：收集 3 个章节线索，或存活到阶段时间后强制进入 Boss 前兆。
- 击败奖励：主线记忆、轮回印记、新功法卡池。

## RPG 叙事节奏

叙事应是“线性主线 + 轮回补片”。

### 单局内节奏

1. 开局选择命格。
2. 进入章节地图。
3. 前 1 分钟建立基础构筑。
4. 第一次剧情点位出现，给主线线索。
5. 第一波精英潮出现，给高价值奖励。
6. 第二个剧情点位给选择和代价。
7. 章节线索达到阈值，Boss 前兆出现。
8. Boss 战。
9. 死亡或击败 Boss 后进入轮回结算。

### 多局轮回节奏

1. 第一局：知道大荒异变。
2. 第二局：知道主角前世与青丘有关。
3. 第三局：知道 Boss 与轮回因果有关。
4. 多次轮回：补足碎片、解锁不同命格视角。
5. 普通结局：击败章节 Boss 但未理解真相。
6. 真结局：收集关键记忆，选择正确剧情路径，完成最终轮回。

## 最新版本优先级

### V0.3.2 正式场景地图版

目标：先解决“场景不像正式美术”的最大观感问题。

任务：

- 正式无限地图场景包。
- 第一章青丘/荒境基础地貌。
- 可重复边缘过渡。
- 动态场景摆件第一批。
- 剧情点位视觉重做。
- 降低程序化原型底图权重。

验收：

- 一眼不再像原型地图。
- 跨屏移动时没有明显拼接块。
- 剧情点位和普通摆件能区分。

### V0.3.3 数值机制与构筑版

目标：补齐吸血鬼like必要成长节奏。

任务：

- 经验曲线。
- 怪物成长曲线。
- 掉落节奏。
- 卡牌稀有度。
- 刷新/跳过/锁定消耗。
- 当局构筑查看。
- 至少 3 条功法进化链。

验收：

- 玩家能感到每次升级都有意义。
- 构筑不是单纯加数值。
- 选择卡牌后能看到技能变化。

### V0.3.4 怪物潮与 Boss 战设计版

目标：让一局内有阶段压力和章节目标。

任务：

- 怪潮时间轴。
- 普通潮、精英潮、事件潮。
- 精英奖励。
- 第一章 Boss 触发条件。
- Boss 阶段与技能池。
- Boss 战 UI 与奖励。

验收：

- 每 60-90 秒有明显阶段变化。
- 精英出现有压迫和奖励期待。
- Boss 是章节目标，不是随机大怪。

### V0.3.5 章节叙事与轮回版

目标：建立 RPG 叙事差异化。

任务：

- 主线章节文本。
- 剧情点位短事件。
- 选择后果。
- 轮回记忆。
- 命簿记录。
- 普通结局/真结局条件雏形。

验收：

- 玩家知道自己在推进主线。
- 死亡后仍觉得故事前进了。
- 轮回不是纯数值重开。

### V0.3.6 美术资产扩充版

目标：补齐角色、怪物、Boss 正式资产。

任务：

- 更多小怪行走图。
- 更多精英怪行走图。
- 第一章 Boss 动作帧。
- Boss 专属场景资源。
- 更多动态摆件。

验收：

- 敌人不再单调。
- 精英和 Boss 有明显辨识度。
- 同屏资源压力仍可控。

### V0.3.7 爽感补完版

目标：用机制、动效、音效提升爽感，而不是堆数值。

任务：

- 技能动特。
- 美术字飘字。
- 资源飞入 UI。
- 命中、拾取、升级、选卡、剧情触发音效。
- 探索/敌潮/Boss 音乐层。

验收：

- 技能进化后画面明显变强。
- 命中和击杀有反馈。
- 音效不吵，但能增强手感。

### V0.3.8 竖屏移动端专项

目标：验证手机 HTML 可玩。

任务：

- 竖屏 HUD。
- 竖屏升级卡。
- 竖屏剧情事件。
- 触控摇杆。
- 神通按钮。

验收：

- 手机竖屏能完成 3-5 分钟局内循环。
- UI 不遮挡核心战斗区域。

### V0.3.9 线上版本部署

目标：提供可分享、可测试的线上版本。

任务：

- 整理发布目录。
- 压缩 runtime 资源。
- GitHub 仓库整理。
- GitHub Pages 或静态站部署。
- ChatGPT 内可访问/展示的版本说明。
- 发布说明、版本号、体验入口。

验收：

- 可通过链接打开。
- Chrome、Edge、手机浏览器基本可玩。
- 有明确版本说明和反馈入口。

## 下一次开工建议

下一次优先进入：

**V0.3.2 正式场景地图版**

理由：

- 当前最影响第一眼观感的是场景。
- 地图底子不成立，UI 和角色都会被拖回原型感。
- 场景点位也是后续剧情、轮回、Boss 的承载层。

V0.3.2 不建议先追求全量大地图，而是先做一套可验证的“第一章青丘/荒境正式地图包”，把正式场景、事件点位、动态摆件和无限延展规则跑通。
