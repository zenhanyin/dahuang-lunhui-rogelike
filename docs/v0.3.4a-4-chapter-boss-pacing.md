# V0.3.4a-4 First Chapter Story/Boss/Pacing Verification

Date: 2026-08-08

## Goal

Make the first chapter feel less like endless survivor combat and more like a structured RPG-survivor run:

- story memories affect the current run;
- elite and Boss beats are readable;
- Boss has phases instead of acting as a large elite;
- death/clear still returns memory progress.

## Runtime Changes

- Added lineage-aware first chapter story data for Xuanyuan and Qingqiu.
- First memory now grants immediate run feedback:
  - Xuanyuan: sword damage boost.
  - Qingqiu: pickup range boost.
  - both lines: small survival/resource reward.
- Second memory now applies `state.chapter.bossWeaken`, reducing first chapter Boss max HP on entry.
- Boss now has three verification phases:
  - phase 1: entry pressure;
  - phase 2: summon guard enemies;
  - phase 3: enrage, faster ground rupture cadence and shockwave pressure.
- Boss frame now reports phase text, for example `三阶段 狂燃`.

## Verification

Passed:

- `tools/smoke-test.mjs`
- `tools/probe-chapter-v034a.mjs`
- `tools/probe-chapter-v034a4.mjs`

`probe-chapter-v034a4` confirms:

- first and second memories are both recorded;
- story reward has a real run effect;
- second memory weakens Boss HP;
- Boss can enter summon and enrage phases;
- Boss summons enemies;
- Boss phase UI updates.

## Known Weak Spots

- Boss uses current monster/VFX assets and is not yet a final chapter Boss art pass.
- Ground rupture warning uses existing VFX composition, not a dedicated formal telegraph atlas.
- Audio is still procedural and verification-level.
- First chapter timing still needs manual real-play tuning after this pass.
