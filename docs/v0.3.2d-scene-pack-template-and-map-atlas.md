# V0.3.2d 地图资产包模板与双出生地图图集

日期：2026-07-27

## 目标

把青丘场景验证出的结构固化为可复用 scene pack 模板，并为另外两个主角出生地：轩辕遗剑、神农丹徒，补第一版正式 WebP 图集。

## Scene Pack 标准结构

每个出生地图至少包含：

- `*_seamless/`：4 张同边缘规则的 `512x512` base tile。
- `decals/`：3-6 张低对比地表痕迹，用于减少重复感。
- `props/`：5-12 张贴地摆件，静态与小循环动画分开。
- `events/`：剧情点位三态资源，必须有 `idle / ready / done`。
- `manifest.json`：记录图集结构，后续替换美术图件时保持 key 不变。

运行时规则：

- `tileAtlas` 存在时，地图走 tile 无限拼接。
- `scenePack` 决定该地图可使用的 decal、prop、event 类型。
- UI 图件不能混入世界场景层。
- 动态空气层后置，不和地表 decal 混在一起。

## 当前注意点

这批图件是 V0.3.2d 第一版地图图集模板，重点是验证“目录、key、无限拼接、层级、体量”。后续可以在不改代码结构的情况下，用更精细的正式美术替换同名 WebP。

下一轮需要重点跑测：

- 三个主角开局是否分别进入对应地图。
- 轩辕/神农 tile 是否有明显拼接线。
- 轩辕/神农摆件是否贴地，不随屏幕漂浮。
- 剧情点位是否有 idle / ready / done 三态。
- 青丘是否未被通用逻辑破坏。
