# V0.3 当前进度跑测评审

项目：《大荒轮回录：荒境》

评审时间：2026-07-22

## 本轮跑测结论

当前版本号：`0.3.1-ui-nineslice`

本轮验证了基础玩法、资源审计、视觉状态截图和怪物压力。结论是：当前版本已经能作为 V0.3.1 的可跑验证版，但还不能视为正式美术体验版。

## 本轮已修 BUG

### 移动端截图流程错误

问题：

- `visual-mobile-choice.png` 原本是在死亡结算后直接切竖屏截图。
- 这导致图片看起来像移动端卡牌 UI，但实际截到的是结算态。
- 之前对竖屏升级卡的判断因此不可靠。

修复：

- 在 `tools/visual-run.mjs` 中，竖屏截图前重新隐藏结算/暂停/剧情层，恢复玩家状态，并显式打开升级卡牌。
- 现在 `visual-mobile-choice.png` 能正确展示竖屏升级三选一。

### 资源审计漏检地图资产

问题：

- `src/game.js` 会加载 `assets/maps/wilds-runtime.webp` 和 `assets/maps/qingqiu-runtime.webp`。
- 但审计脚本没有检查这两张 runtime 地图是否存在。

修复：

- 在 `tools/audit-style-systems.mjs` 中加入 `missingRequiredRuntimeAssets`。
- 现在会检查关键地图和九宫格 UI 资源。

## 当前代码状态

### 稳定性

当前代码能稳定跑完基础流程，但仍属于快速原型到正式框架之间的状态。

优点：

- 玩法主循环完整。
- 配表已能承载角色、地图、升级、敌人和数值。
- Runtime WebP 资源路径清晰。
- 九宫格 UI 已初步工程化。
- 有 smoke、audit、visual、stress 四类测试脚本。

问题：

- `game.js` 仍然承担过多职责：状态、战斗、地图、绘制、音效、UI 都在一个文件里。
- 地图绘制仍混合正式底图与程序化纹理，导致视觉判断困难。
- 构筑系统还只是记录与摘要，没有形成独立模块。
- 剧情点位逻辑有雏形，但缺少事件状态机和章节推进。
- 音频仍是 Web Audio 合成验证，没有正式资源管理层。

## 当前美术资源状态

### UI

已完成：

- V0.3.1 九宫格 UI 底层。
- HUD、资源框、开局卡、升级卡、剧情框、暂停框、结算框和按钮已接入。

差距：

- 当前 UI 更像“工程组件”，还不够接近定帧图。
- 缺少独立装饰件：卷轴轴头、莲纹题头、飞天飘带、角色挂饰、边角铜扣、按钮高亮层。
- 卡牌缺少稀有度、流派、消耗/免费状态、构筑关联。
- 竖屏 UI 可显示，但遮挡大，不能视为正式移动端布局。

### 场景地图

已完成：

- 有 `wilds-runtime.webp` 与 `qingqiu-runtime.webp`。
- 有随机摆件和跨屏地图。

差距：

- 目前不是完全原型图，但观感仍偏原型。
- 正式底图权重不够，程序化底图、纹理线和随机摆件仍在主导画面。
- 无限地图没有真正的正式章节地图包。
- 剧情点位和普通摆件区分不足。
- 地图还没有承担主线叙事、轮回变化和 Boss 前兆。

### 角色与怪物

已完成：

- 三个主角已有左右行走帧。
- 小怪/精英已有基础行走帧。

差距：

- 普通怪种类少。
- 精英怪职责不清。
- Boss 没有动作帧。
- 怪物受击反馈、死亡反馈和入场提示不足。

## 音乐音效问题

当前音频是 Web Audio 合成验证，优点是轻量，缺点是风格和反馈都不够正式。

主要问题：

- 没有正式 BGM。
- 没有探索层、敌潮增强层、Boss 层的音乐分层。
- 命中、击杀、拾取、升级、选卡、剧情触发之间区分不够。
- 打击反馈不够明确。
- 剧情点位没有形成低压、神秘、残响的氛围。
- Boss 音乐和警示音完全缺位。

后续方向：

- 保留 Web Audio 作为 fallback。
- 接入轻量正式音频资源。
- 先做最小音频包：探索循环、敌潮增强、Boss 压迫、命中、击杀、拾取、升级、选卡、剧情触发、神通释放。
- 音效必须绑定机制，不做纯装饰。

## 技能表现问题

当前技能已有基础表现：

- 飞剑
- 飞符
- 幻雾
- 丹火
- 冲刺
- 拾取
- 飘字

主要问题：

- 技能变强后视觉差异不够明显。
- 构筑选择后没有“技能形态变化”的强反馈。
- 飞剑、飞符、幻雾、丹火缺少分支表现。
- 飘字仍然不像正式美术字。
- 命中和击杀反馈不够爽。
- 神通/冲刺的仪式感不足。

后续方向：

- 飞剑：拖尾、剑痕、剑阵、命中爆光。
- 飞符：符纸轨迹、符咒锁敌、分裂、冰裂/雷纹。
- 幻雾：范围边界、狐影残像、敌人减速状态。
- 丹火：地面火印、爆燃、灼烧、拾取触发小爆。
- 冲刺/神通：蓄力环、残影、释放冲击、短暂无敌提示。
- 每条功法进化链都要有明显视觉变化。

## 当前最大风险

1. 场景底子不成立，会继续拖累 UI、剧情和 Boss 的观感。
2. 构筑系统没有进化链，玩家会觉得升级只是加数值。
3. 怪潮没有阶段设计，一局缺少节奏。
4. 剧情点位还没有主线推进感，差异化尚未真正成立。
5. 音乐音效和技能反馈短板明显，爽感不足。
6. 移动端需要单独设计，不适合直接缩放横屏 UI。
