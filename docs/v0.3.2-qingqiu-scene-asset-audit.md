# V0.3.2 Qingqiu Scene Asset Audit

Date: 2026-07-23

## Current Runtime State

- Runtime map: Qingqiu uses `tileAtlas: qingqiu_seamless`.
- Base tiles: `tile_qingqiu_base_seamless_01/02/03.webp`, selected by stable world tile hash for infinite scrolling.
- Ground decals now favor old vow trace, ink-teal veins, and pale gold mural line remnants.
- Deprecated large purple fog pools are no longer used by Qingqiu generation.
- Runtime props/events: Qingqiu foxfire small/medium/cluster, low grass, fox-mask shard, ground ribbon, old vow stele, optional rift.
- Story events generated in Qingqiu: `foxfireVow`, `oldVowStele`, optional `rift`.

## Visual Read

- The current base tile set is much safer than the earlier programmatic flat ground and supports infinite scrolling.
- The ground now reads as old fresco/mineral texture instead of large pasted purple pools.
- Event points no longer depend on a floating `缘` label. The prop states carry idle/ready/done feedback.
- Current foxfire prop pass is readable but a little too crystalline; next pass should feel more like soft foxfire flame.
- UI is still a separate issue: HUD and story panels need the formal atlas pass to fully match the concept frames.

## Runtime Changes

- Qingqiu generation now uses dedicated feature types instead of generic `foxfire`, `grass`, and `stele` as the primary set.
- Story types now include `foxfireVow` and `oldVowStele`.
- `drawTiledMapBase` now hashes world tile coordinates to choose among three base tiles.
- `drawSceneEventFeature` now draws Qingqiu event state art based on idle, near-player ready, and seen/done states.
- Smoke test now checks `qingqiuSceneAssets: true`.

## Remaining Gaps

- Foxfire needs a more painterly flame silhouette and less crystal/mineral read.
- Old vow stele ready state should become more ceremonial and obvious without becoming a floating label.
- Story dialog UI is still using the current generic panel style and needs its own atlas.
- Dynamic air mist is still deferred; it should be a separate atmosphere layer, not ground decal.
- Generic rift/stele fallback can remain low-density, but chapter-specific versions should replace them later.

## Priority

P0:
- Keep the three safe seamless base tiles as the shipped Qingqiu fallback.
- Keep large purple fog pools out of the ground layer.
- Verify no obvious rectangular seams after extended movement.

P1:
- Make a second foxfire loop pass.
- Make a stronger old vow stele ready/done pass.
- Build dedicated story dialog atlas and event prompt UI.
- Tune Qingqiu prop density after gameplay screenshots.

P2:
- Add dynamic atmosphere layer after ground/decal/prop layers are stable.
- Revisit richer multi-tile atlases only after they pass 3x3 and in-game movement QA without visible seams.

## Acceptance Checklist

- No obvious rectangular seams after 2 minutes of movement.
- Qingqiu can be recognized with HUD hidden and without characters/enemies.
- Story point remains readable without a floating `缘` label.
- Props share fresco grain, outline softness, and mineral palette with the ground.
- Asset budget remains web-friendly and individual props stay as small WebP files.
