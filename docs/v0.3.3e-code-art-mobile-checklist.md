## HTML 资源预算原则

- 单个场景包优先控制在 2-4 MB WebP 内，首屏只加载当前主角出生地图。
- base tile 少而稳，随机性主要靠低透明 decal、低矮摆件和事件点位分布。
- 小怪采用共享骨架尺寸和少帧循环，精英/Boss 才增加动作帧。
- 动特优先使用小尺寸 atlas、颜色复用和粒子数量上限，不做大面积透明视频层。
