# V0.3.2b UI 收口与青丘样板验收

日期：2026-07-27

## 本轮结论

V0.3.2b 已经具备“可试玩、可评审”的青丘样板：正式青丘 base tile 已接入，地图可跨屏无限延展；HUD、升级卡牌、剧情弹框、暂停、当局构筑、结算都已脱离主要原型框架，进入正式 UI 图件接入阶段。

但当前仍不是最终 UI 质感。主要问题集中在：正式 UI atlas 颗粒度不足、构筑界面仍像账本、剧情点位反馈还依赖程序绘制、手机端只是可跑版本。

## 已验证

- `tools/smoke-test.mjs`：通过。
- `tools/audit-style-systems.mjs`：通过，无缺失运行时资源、无禁用原型资源引用。
- `tools/visual-run.mjs`：通过，覆盖开局、战斗、升级卡、暂停、构筑、剧情、结算、手机选择状态。
- `tools/visual-qingqiu-loop.mjs`：通过，确认使用 4 张 `qingqiu_base_final_*` tile 和 24 个青丘摆件/事件资源。
- `tools/stress-probe.mjs`：通过，60 怪基础压力约 4ms/帧；真实特效压力截图约 9-10ms/帧。

## 本轮修正

- 缩小并重排桌面 HUD，减少左上卷轴压屏感。
- 调整剧情弹框正文区域，使文本更贴合卷轴主阅读区。
- 调整升级卡牌说明区行距和宽度，减少文本压框感。
- 调整当局构筑面板排版，改为更稳定的单列账本结构。
- 更新 `index.html` 样式版本号，减少缓存误判。

## 青丘样板状态

可作为后续地图资产模板的部分：

- base tile：4 张同边缘逻辑的青丘无缝地表图，可支持上下左右循环。
- decal：旧誓线痕、墨青脉络、淡金壁画残线方向成立。
- props：狐火、低草、狐面碎片、地面残绦方向成立。
- event：旧誓残碑、狐火旧约已有 idle/ready/done 三态资源。
- 性能：当前 WebP 资源包体量仍可控，适合 HTML 继续承载。

仍需补强：

- 青丘 base tile 需要再补 2-4 张同明度、同边缘标准的变体，降低长时间奔跑重复感。
- 地表 decal 需要增加更细碎、小尺寸、低对比版本，避免少数纹样重复出现。
- 事件点位需要独立交互提示图件，不能长期依赖程序画圆和“缘/记”字。
- 动态空气幻雾层暂未做，应和地表 decal 分层。

## UI 缺口

P0：

- 当前构筑 UI 需要专属 atlas：路线章、功法条目、进化节点、剧情印记分区。
- 暂停/结算仍缺专属内容结构，尤其是“轮回记忆、构筑回顾、解锁预告”。
- 剧情点位提示需要正式三态图件：未触发、可触发、已记录。

P1：

- 资源框、暂停章、等级章、冲刺章已共用 atlas，但还需要统一明暗和描边厚度。
- 技能属性 icon 需要统一重绘，当前能用但不够像同一套敦煌 UI。
- 升级卡牌需要加入构筑类型、当前等级变化、可进化提示、拒选/关闭逻辑。

P2：

- 手机端需要单独 UI atlas 和布局，不继续缩放桌面卡牌。
- 当局构筑入口在手机端需要更清楚的位置和触控热区。

## 玩法逻辑缺口

- 构筑反馈仍弱：玩家选择卡牌后，普通攻击/技能形态变化不够明确。
- 升级经验已显示差值，但缺“即将升级”的屏幕反馈。
- 剧情点位触发节奏已有雏形，但还没形成线性主线节奏。
- 怪潮和 Boss 战还未进入正式节奏结构。
- 局外轮回成长已有点数入口，但还没有真正的局外树/记忆补全系统。
