# V0.3.3l 当前进度与下一步清单

- 当前运行 hook：`0.3.3l-client-opt`。
- 资源审计通过：`tools/audit-assets.mjs` 返回 `ok: true`。
- UI/样式审计通过：`tools/audit-style-systems.mjs` 返回 `ok: true`。
- 安全区审计通过：`tools/audit-ui-safe-areas.mjs` 返回 `issueCount: 0`。
- HTML 客户端已做基础优化：移动端样式独立加载、Canvas 上下文优化、图片异步解码、HUD DOM 同步节流、resize 节流、触摸摇杆稳定化。

- P1 第一刀已完成：新增 `styles-ui.css` 作为桌面正式 UI 权威层，加载顺序调整为 `styles.css` -> `styles-ui.css` -> `styles-mobile.css`，审计脚本已同步扫描三份样式文件。
- P1 二阶段已完成：`styles.css` 中 `V0.3.2b` 之后的历史 UI 补丁被 `@media not all` 隔离，运行态由 `styles-ui.css` 和 `styles-mobile.css` 接管。

## 已基本稳定

- 吸血鬼like基础循环：移动、自动攻击、拾取、升级三选一、跳过、冲刺、死亡结算。
- 三主角开局逻辑。
- 青丘场景样板：可作为场景包结构和风格参考，但目录仍在 `v032_atlas`，后续可迁移到 `v033/qingqiu`。
- 轩辕场景方向：纯俯视、敦煌壁画残纹、裂土、剑痕、低矮残器方向成立。
- 正式 UI 图件路线：HUD、资源框、开局卡、升级卡、剧情框、按钮已经从“程序拼 CSS”逐步转向正式图件。
- 移动端基础可玩：竖屏开局确认、升级卡、剧情框已能显示和操作。

## 仍然不稳

- `styles.css` 仍有多轮历史补丁，虽然当前由后置规则压住，但长期维护风险高。
- `styles.css` 的历史补丁已被隔离但尚未物理删除；下一步可以在截图回归稳定后，把旧块迁移为归档文档或彻底删除。
- 竖屏 UI 仍是桌面 UI 适配，不是专属移动端 atlas，升级卡和开局卡视觉占比偏大。
- 开局选人、升级卡、剧情框的文字安全区仍需要继续按 `docs/ui-atlas-safe-area-spec.md` 严格约束。
- 当前构筑 UI 还不够强，玩家对本局功法、等级、进化线的感知不足。
- 轩辕地图摆件和事件点位还偏少，长时间移动后重复感明显。
- 第三主角线已移出当前 MVP，后续优先把轩辕 / 青丘双线打磨到可玩闭环。
- 怪物群、精英怪、Boss 仍是后续核心缺口。
- 音乐、音效、技能动特还停留在验证层，爽感和机制反馈仍弱。

## 下一步优先级

### P0：收口当前工作区

目标：先让当前版本可稳定回归和部署。

- 检查并确认当前未提交改动的归属：资源台账、UI 收口、移动端 CSS、客户端优化。
- 能构建时重新生成 `deploy-root`，若目录被预览进程占用，先关闭本地预览再构建。
- 跑完整回归：资源审计、样式审计、安全区审计、桌面截图、移动端截图。
- 同步线上版本，确保 GitHub Pages / 线上链接拿到 `0.3.3l-client-opt`。

### P1：V0.3.3i UI 收口二阶段

目标：把 UI 系统从“历史补丁覆盖”整理成可维护结构。

- 拆分样式层：`base.css`、`ui-atlas.css`、`styles-mobile.css`。
- 清理 `styles.css` 中旧按钮、旧面板、旧卡牌、旧移动端补丁。
- 统一 HUD、资源框、暂停、结算、开局选人、升级卡牌、剧情框排版。
- 保留正式图件作为主视觉，不再依赖 CSS 边框和程序拼装。
- 建立 UI 回归截图清单：桌面开局、桌面升级、桌面剧情、桌面暂停、桌面结算、竖屏开局、竖屏升级、竖屏剧情。

### P2：V0.3.3j 轩辕样板收尾

目标：把轩辕从“方向正确”推进到“可作为第二个正式地图样板”。

- 补 2-3 张同风格 base tile，避免单一纹理重复。
- 补低矮残器、断剑、剑痕、裂土、残旗碎片等正式摆件。
- 事件点位使用“小型石盘本体 + 极弱呼吸光环 + 靠近提示 + 已记录状态”。
- 检查无限循环拼接：不能出现明显大块重复、糊边、浮层、伪 3D 透视。
- 对比青丘样板：明确哪些是地图通用规范，哪些是轩辕专属视觉语言。

### P3：V0.3.4 双线章节地图与剧情推进

目标：不再扩第三主角，先把轩辕 / 青丘两条开局线接入第一章主线节奏。

- 青丘 / 轩辕各保留独立出生场景和场景事件。
- 第一章公共荒境地图承接两条线的主线剧情、精英潮和 Boss。
- 接入同一套地图包逻辑，不为不同主角单独写代码。
- 跑青丘 / 轩辕双地图切换回归。

### P4：V0.3.4a 怪物群与精英怪

目标：补齐吸血鬼like的压力曲线。

- 每个出生场景至少 2 种小怪、1 种精英怪。
- 先做三类行为模板：追击、远程、地面残留/范围压迫。
- 小怪图集目标：`walk 4 + hit 1 + death 3`，单种 80-180 KB。
- 精英图集目标：增加 `cast/enraged`，单种 180-300 KB。
- 同屏怪物多时继续做降帧、对象池、远处简化。

### P5：V0.3.4b 构筑与技能反馈

目标：让升级和功法选择真的有爽感。

- 做“当前构筑 UI”：本局功法、等级、流派标签、进化条件。
- 补功法进化链：至少 3 条可验证进化。
- 强化飞剑、符咒、火、幻雾、回血的动特差异。
- 替换仍像程序画的轨迹、圈、命中特效。
- 卡牌选择后要有音效、光效、技能变化反馈。

### P6：V0.3.5 移动端专项

目标：不再用桌面 UI 强行缩放。

- 制作竖屏专属 HUD atlas。
- 制作竖屏专属开局选人卡和升级小卡。
- 开局选择采用横滑卡 + 底部大确认按钮。
- 升级选择采用单卡聚焦 / 横滑三卡 / 底部固定操作区。
- 剧情框做竖屏专属版，文本和头像安全区独立设计。

### P7：V0.3.6 叙事与轮回

目标：建立和普通吸血鬼like的差异。

- 第一章主线节奏：开局、第一次剧情点、精英潮、第二剧情点、Boss 前兆、Boss。
- 轮回记忆：死亡结算不只是失败，而是推进线索。
- 真结局条件：通过多次轮回补齐关键碎片。
- 剧情点位要和地图、怪潮、构筑、Boss 前兆产生联系。

## 建议下一步

建议先做 `P0：收口当前工作区`，把当前 `0.3.3l-client-opt` 稳定成一个可回归、可部署版本。

之后进入 `P1：UI 收口二阶段`。原因是 UI 历史补丁还很多，如果现在继续铺怪物和 Boss，后面移动端和卡牌界面会继续被旧 CSS 干扰。

当前已经进入 `P1` 的第二步：正式 UI 覆盖层已从历史 `styles.css` 中分离为 `styles-ui.css`，旧移动端、旧卡牌和旧面板补丁已被隔离。下一步不是继续加新覆盖，而是做截图回归后，物理删除被隔离的历史块。

UI 稳住后，再做 `P2：轩辕样板收尾` 和 `P3：双线章节地图与剧情推进`，这样青丘 / 轩辕两条出生线能统一到正式场景资产规范和第一章玩法骨架里。
