# V0.3.3j UI Atlas Safe Area Update

Date: 2026-07-31

## Summary

Added the formal UI text safe-area spec:

- `docs/ui-atlas-safe-area-spec.md`

This spec is now the reference for future UI atlas generation, slicing, and HTML/CSS placement.

## Why

Recent UI bugs came from aligning live text and icons to DOM boxes instead of the actual painted UI frame:

- story titles touched the title plaque border;
- upgrade card icons/text looked off-center;
- start-card selected state used a rough CSS rectangle;
- resource counter atlas was accidentally stretched.

The root issue is that formal Dunhuang UI pieces have decorative overhangs, crowns, scroll rods, lotus bases, and asymmetric ornaments. Their visual center is not always `50%` of the exported transparent image.

## New Required Rule

Every formal UI piece must define:

- `outerBox`: full transparent image bounds;
- `paintedBox`: visible painted frame bounds;
- `textSafeBox`: where live text can appear;
- `visualAxis`: the axis used by icons, labels, titles, buttons, and selected states.

CSS should align to `textSafeBox` and `visualAxis`, not to the full image box.

## Applies To

- Upgrade card UI.
- Start lineage card UI.
- Story dialogue panel.
- Resource counter / pause / level / dash atlas.
- Pause, result, build, codex, and future event panels.
- Mobile portrait card layouts.
