# V0.3.4a Enemy Asset Prep

## Goal

Before building the first chapter playable spine, add a small set of formal WebP enemy walk-frame variants so wave pressure is not visually represented by one repeated monster.

## Added Runtime Enemy Sets

- `blade_thrall`: Xuanyuan sword-tomb small enemy, bronze/ochre palette, residual blade strokes.
- `stone_imp`: slow tanky small enemy, muted stone and oxidation palette.
- `foxshade`: Qingqiu fast small enemy, violet fox-shadow tail trails.
- `cinnabar_guard`: elite enemy variant, cinnabar/red guardian palette.

Each set includes left/right 3-frame WebP walk cycles under:

`assets/runtime/webp/enemies/`

## Integration

- Registered all new frames in `src/game.js` runtime asset table.
- Added new enemy stats in `src/config.js`.
- Updated map `enemyPool` values so Xuanyuan and Qingqiu have distinct enemy mixes.
- Updated spawn selection to separate normal pools from elite pools.
- Updated enemy rendering to use `enemy.type` instead of forcing all non-elite enemies to `wraith`.
- Synchronized `assets/asset-manifest.v0.3.json`.

## Runtime Budget

The 24 new WebP frames add roughly 281 KB. This is acceptable for the current HTML client because the whole formal runtime manifest remains near 1 MB, while heavier concept/source folders are still excluded from runtime.

## Next
