# V0.3.2 正式场景地图版规划

项目：大荒轮回录：荒境  
目标：把当前偏原型感的无限地图，升级为可重复拼接、可承载剧情点位、能支撑章节推进的正式场景地图系统。

## 当前判断

现有工程已有 `wilds-runtime.webp`、`qingqiu-runtime.webp`、`terrain` 摆件和 `scene/qingqiu` 资源，但实际画面仍有三个问题：

1. 正式底图权重不足，程序纹理、色块、重复雾池和边框感太强，导致像原型地图。
2. 无限延展缺少专门的边缘过渡图件，移动后容易看到块状衔接和大面积重复。
3. 剧情点位只是“碑/火 + 缘字标记”，缺少可交互状态、吸引玩家靠近的视觉层级，也没有清楚表达“这是主线/支线/轮回记忆”。

V0.3.2 不先扩展怪物和技能，而是先把地图场景做成正式地基。

## 场景资产分层

正式地图包按 6 层管理：

1. 地貌底图层  
   章节主地貌，负责第一眼风格和大面积色彩。需要低重复、可裁切、边缘可衔接。

2. 地貌过渡层  
   用于掩盖无限地图块衔接，包括雾带、沙尘、岩纹、暗角、断裂地表、远景云纹。

3. 随机摆件层  
   草、残骨、碎石、残碑、小型灵火、枯枝、经幡、遗物。只负责环境丰富度，不抢剧情点位。

4. 剧情点位层  
   可交互对象，必须有状态：未激活、可接近、可触发、已记录、已完成。视觉上要比普通摆件更醒目。

5. 章节变化层  
   随时间、轮回、剧情推进改变地图观感，比如雾变厚、碑文显现、赤裂扩散、妖气入侵。

6. Boss 前兆层  
   Boss 出现前的场景警告，包括中心战场、边缘压暗、地面符纹、裂隙、风火/雾气流动。

## 缺失场景清单

### P0：本版必须补齐

1. 三主角出生场景包  
   开局有三个主角，出生场景必须服务角色身份，不能只有青丘一套入口。三套出生场景共享同一章地图规则，但初始区域、摆件、剧情点位和色彩倾向不同：
   - 轩辕遗剑：旧战场 / 剑冢荒境。重点元素是断剑、古战痕、残旗、碎碑、金铁冷光。
   - 青丘巫女：青丘残梦 / 狐火梦渊。重点元素是梦雾、狐火、旧誓碑、紫青雾池。
   - 神农丹徒：百草荒泽 / 丹火遗圃。重点元素是药草、丹炉残火、灵井、赤土裂纹、草木灵光。

2. 第一章正式主地图包  
   第一章可以仍以“荒境”为统一大地图，但根据主角和轮回状态抽取不同场景模块。青丘残梦是其中一个高优先模块，而不是唯一地图。需要：
   - `ground_qingqiu_a.webp`：主地貌，灰紫泥土、旧碑、梦雾痕迹。
   - `ground_qingqiu_b.webp`：变化地貌，雾池更密、旧誓残痕更多。
   - `ground_sword_tomb_a.webp`：轩辕遗剑出生地貌，荒土、剑痕、断碑、残旗。
   - `ground_herb_marsh_a.webp`：神农丹徒出生地貌，荒泽、药草、丹火、灵井。
   - `transition_mist_edge_*.webp`：大块雾带和暗角过渡。
   - `transition_dust_edge_*.webp`：荒土/剑冢边缘过渡。
   - `transition_herb_edge_*.webp`：草泽/丹火边缘过渡。
   - `decal_crack_*.webp`：地裂、旧线、符痕。
   - `decal_mist_pool_*.webp`：低频大雾池，避免满屏重复。

3. 荒境入口 / 出生安全区  
   角色开局和前 30 秒需要清楚、稳定、低压迫感的可读区域。需要：
   - 三主角各自出生地面底图。
   - 轻量灵火。
   - 低密度草石骨摆件。
   - 不遮挡角色的中心留白。

4. 剧情点位正式资源包  
   剧情点位是差异化核心，本版需要先做到“玩家一眼知道能交互”。需要：
   - `event_stele_idle.webp`：旧誓残碑，未激活。
   - `event_stele_available.webp`：可触发，碑文微亮。
   - `event_stele_done.webp`：已记录，光弱化。
   - `event_foxfire_idle.webp`：狐火线索。
   - `event_foxfire_available.webp`：可触发，火焰外圈和引导光。
   - `event_memory_fragment.webp`：轮回记忆碎片。
   - `event_broken_sword.webp`：轩辕遗剑专属线索。
   - `event_herb_cauldron.webp`：神农丹徒专属线索。
   - 点位底座光圈：主线、支线、轮回记忆三种颜色或纹样区分。

5. 无限地图边缘衔接图件  
   目前块状感明显，本版需要：
   - 横向大雾带。
   - 斜向云纹带。
   - 大面积暗纹遮罩。
   - 地面色差过渡斑块。
   - 远景纹样淡层。

6. 地图资源 manifest  
   场景不能再散落硬编码。需要能描述：
   - 地图包 id。
   - 主底图列表。
   - 过渡层列表。
   - 摆件池。
   - 剧情点位池。
   - 权重、尺寸、碰撞、交互半径、显示层级。

### P1：紧随其后

1. 荒原试炼正式地图包  
   作为第二张可切换地图，色彩比青丘更土黄、荒凉，但不能变成普通沙漠。

2. Boss 前兆场景包  
   章节 Boss 出现前需要地图变奏：
   - 地面符阵。
   - 赤裂中心。
   - 边缘压暗。
   - 大型雾旋。
   - Boss 入口或封印门。

3. 轮回变化层  
   每次重开后，地图上出现不同记忆残痕：
   - 新碑文。
   - 旧梦残影。
   - 前世战痕。
   - 已解锁剧情点位的弱提示。

4. 竖屏裁切版地图适配  
   同一套地图要支持手机竖屏，中心区域不能被 HUD、卡牌和虚拟摇杆遮挡。

### P2：后续扩展

1. 章节二/章节三主题地图。
2. 天候和时间变化：夜雾、赤火、风沙、月影。
3. 大型动态摆件：经幡、莲池、符阵、风带。
4. 地图事件专用小场景：破庙、古井、妖市遗址、轮回门。

## 资产规格建议

为了控制 HTML 内存和加载压力，V0.3.2 采用 WebP 分包。

- 主地貌底图：1280x720 或 1536x864，WebP，单张 250KB 以内优先。
- 大型过渡层：512x512 / 768x384，透明 WebP，单张 80KB 以内。
- 中型摆件：128x128 / 256x256，透明 WebP，单张 20KB 以内。
- 剧情点位：256x256 / 320x320，透明 WebP，单张 40KB 以内。
- 动态摆件：2-4 帧序列，优先复用同一图集，不做大尺寸逐帧动画。

本版地图包总预算建议控制在 1.5MB - 2.5MB，避免移动端压力过高。

## 美术方向约束

场景应保持“古朴、厚重、敦煌壁画感”，但不能压成暗黑仙侠。

- 主色：灰紫、青绿、赭石、旧金、烟墨。
- 明度：中低明度，但角色、敌人、剧情点位周围要留可读光区。
- 纹理：壁画颗粒、旧纸磨损、手绘地裂、云纹线条。
- 禁止倾向：纯渐变背景、现代 UI 霓虹、过亮卡通色、大面积黑雾、重复贴片感。

## 程序接入原则

1. 正式底图优先  
   地图主图应成为画面主体，程序生成纹理只做 10%-20% 的弱叠加。

2. 块状衔接必须隐藏  
   无限地图生成时，每个 chunk 的边缘必须有过渡层随机覆盖，避免出现直线切块。

3. 摆件分密度  
   大雾池和大碑低频，小草、骨、火中频，小裂纹高频但低透明。

4. 剧情点位单独渲染  
   剧情点位不混在普通摆件池里，必须有独立交互半径、状态机和 UI 提示。

5. 地图服务叙事  
   不同章节状态要改变场景，不能只是换文字。例如“旧誓残碑”触发后，附近碑文和雾色应变化。

## V0.3.2 验收标准

1. 第一眼不再像原型地图。
2. 横向移动 2 分钟，不出现明显矩形拼接和重复块。
3. 剧情点位在战斗压力下仍能被识别，并且靠近后有明确反馈。
4. HUD、资源框、剧情点位、角色和怪物互不抢层级。
5. 普通截图和竖屏截图都能保持敦煌壁画调性。
6. 同屏怪物较多时，地图渲染不成为主要卡顿来源。
7. 所有场景资源都由 manifest 接入，不再依赖临时硬编码。

## 建议执行顺序

1. 先制作三主角出生场景 P0 小包：剑冢荒境、青丘残梦、百草荒泽。
2. 再制作第一章公共荒境地图底图和过渡层。
3. 建立 `scene-map-manifest`，把地图底图、过渡、摆件、事件点位统一挂进去。
4. 调整地图渲染权重：正式底图增强，程序纹理压低。
5. 单独重做剧情点位显示和触发反馈。
6. 跑三主角开局截图、桌面横屏、竖屏、2 分钟移动、怪潮压力五类测试。
7. 通过后再补荒原试炼和 Boss 前兆场景。
