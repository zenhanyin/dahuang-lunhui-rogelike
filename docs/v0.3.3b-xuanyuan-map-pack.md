# V0.3.3b Xuanyuan Map Pack

Goal: move the Xuanyuan sword-tomb start map from old `v032_atlas/sword_tomb` assets to the formal `v033/xuanyuan` map pack while keeping the shared `tileAtlas + scenePack` runtime logic.

## Completed

- Generated `assets/maps/v033/xuanyuan/manifest.json`.
- Generated 4 seamless base tiles.
- Generated 5 grounded decals: slash trace, bronze rust, dust stain, broken oath line, ink-shadow line.
- Generated 8 static props: broken blade, torn flag, dry grass, shield shard, bronze fragment, sword mound.
- Generated 1 animated prop set: sword soul glow, 4 frames.
- Generated 2 story marker groups with idle, ready, done states.
- Runtime paths now use `assets/maps/v033/xuanyuan/`.
- Build/deploy skips old `assets/maps/v032_atlas/sword_tomb*` directories.

## Visual Pass

- First formal pack looked too flat and had right-side speckle noise.
- Second pass removed oval decal sticker shapes.
- Current pass uses low-frequency mineral wash, faded cinnabar mural lines, oxidized bronze traces, and thin sword scars.
- Current version is `0.3.3b-xuanyuan-visual-pass`.

## Runtime Budget

- Current Xuanyuan pack: 29 files, about 232 KB.
- This is well under the single map-pack target of 1 MB.
- Loading strategy remains current-map only.

## Keyframe Comparison

Matches:
- Color is now closer to heavy iron-gray and oxidized bronze.
- Decals feel more grounded than the earlier oval patches.
- Sword-tomb props and story marker states are visible in runtime.

Still Missing:
- Large chapter landmarks are not present yet.
- The map is still more restrained than the concept keyframes.
- Future passes need stronger silhouettes: broken sword array, old battlefield ridge, bronze seal gate, or oath altar.

- `tools/audit-style-systems.mjs` passes.
- `tools/visual-run.mjs` passes, with frame timing still safe for HTML runtime.
