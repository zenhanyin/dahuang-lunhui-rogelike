## 当前开发状态

### 已稳定

- HTML Canvas 单机循环：移动、自动攻击、拾取、升级三选一、跳过、冲刺、刷怪、死亡结算。
- 三主角开局逻辑已存在。
- 青丘地图可作为第一个可用场景样板。
- 轩辕地图美术方向已经靠近确认定帧：纯俯视、敦煌矿物壁画感、裂土、云纹、剑痕、低矮残器。
- HUD、资源框、等级章、冲刺章、剧情框、升级卡牌均已接入正式图件路线。

### 仍不稳

- UI 仍有历史 CSS 补丁堆叠，部分界面依赖 CSS 对齐而不是严格按图件留白区排版。
- 开局选人界面可用但布局还粗，需要单独收口。
- 升级卡牌桌面可用，竖屏仍不适合最终一手操作。
- 剧情框图件方向正确，但标题、头像、正文、按钮仍需要精确排版。
- 事件点位已经能看到，但靠近提示、触发反馈、已记录状态还不够有仪式感。
- 构筑信息已有摘要，但缺“当前构筑 UI”作为当局查看入口。
- 技能动效和打击反馈仍有 Canvas 程序绘制痕迹，尚未正式 atlas 化。
- 怪物群、精英、Boss 仍是机制和资产缺口。
