# V0.3.3m Scope Shift: Story Gameplay First

Date: 2026-08-02

## Decision

Remove Shennong from the current MVP scope.

Current playable starts:

- Xuanyuan sword line: `sword_tomb`
- Qingqiu witch line: `qingqiu`

Shennong assets, config and runtime registry entries are no longer part of the active MVP. This keeps the game focused on two clear routes: Xuanyuan sword line and Qingqiu witch line.

## Why

The project should now move from early art iteration into the core differentiator:

- Vampire-like survival loop;
- structured main-story pacing;
- reincarnation memory;
- map story points;
- cultivation/build choices;
- chapter boss progression.

The goal is not to polish the first five minutes forever. The goal is to prove that this is a narrative RPG-flavored survivor game, not only a prettier prototype.

## Next Priority

### P0: First Chapter Playable Spine

Build one complete 6-8 minute loop using Xuanyuan and Qingqiu:

1. Start selection.
2. Early enemy pressure.
3. First upgrade.
4. First story point.
5. Elite wave.
6. Second story point.
7. Mini-boss / chapter boss warning.
8. Boss encounter.
9. Death or chapter clear.
10. Reincarnation memory summary.

### P1: Story Script Integration

Story points should not be random flavor text only. Each point should advance:

- main plot;
- reincarnation clue;
- local scene identity;
- future true-ending condition.

### P2: Build Feedback

Upgrade cards need to visibly change the current run:

- stronger projectile count / cadence / range;
- clearer skill evolution hints;
- current build panel;
- stronger feedback when choosing cards.

### P3: Scene Support

Only add scene art that supports the above loop:

- event point states;
- boss arena accents;
- elite/boss warning visuals;
- low-ground props that make movement readable.

## Deferred

- Any future third lineage or map pack.
- Full mobile-specific UI atlas.
- More chapter map packs.
- Full monster ecology.
- Large-scale UI atlas rework beyond what blocks the first chapter loop.
