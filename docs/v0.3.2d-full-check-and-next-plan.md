# V0.3.2d Full Check And Next Plan

## Check Result

- Runtime logic: pass. Smoke test confirms cross-map movement, chunk streaming, touch movement, pause, free upgrade skip, meta point reward, formal UI asset presence, and Qingqiu scene assets.
- Scene pack logic: pass. Qingqiu, Xuanyuan sword tomb, and Shennong herb marsh all use `tileAtlas + scenePack + map events + scene props`.
- Performance: pass for current HTML target. Stress probe with 60 enemies reports about 4.15 ms/frame on the local test environment.
- Asset loading: pass for required runtime files. No missing required runtime assets in the current audit.

## Fix Applied During Check

- Replaced old variant feature weights in `src/config.js` for Xuanyuan and Shennong maps:
  - `stone/grass/spirit` bias no longer drives the new scene packs.
  - Xuanyuan now biases `swordBrokenBlade`, `swordTornFlag`, `swordDryGrass`.
  - Shennong now biases `herbDanEmber`, `herbMarshPool`, `herbCluster`.

## Current Progress

- V0.3.2b UI close pass: partially complete.
  Formal HUD/card/story assets are in use, but CSS rules are still layered in several historical patches.
- V0.3.2c point feedback: partially complete.
  Story point states are visible and interactive, but generic badge/underlay overlays can still feel like stickers on top of scene props.
- V0.3.2d scene pack template: structurally complete.
  Three map packs can be selected and rendered through the same pipeline.

## Main Issues

- UI is not fully unified yet. HUD, pause, result, story, build, and upgrade cards use formal assets, but some smaller pieces still depend on CSS sizing, CSS backgrounds, or old shared button styling.
- Scene tile quality differs by map. Qingqiu is the closest to the intended standard. Xuanyuan and Shennong are usable templates, but seams and repeated tile motifs are still visible.
- Old fallback paths remain in code and manifest, including legacy transition and mist-pool references. They are mostly dormant for current formal maps, but should be cleaned before expanding chapters.
- Current build UI is functional but still not strong enough as a Vampire-like in-run build readout. It needs clearer skill level, owned passive, evolution route, and locked/available state.
- Skill VFX, hit feedback, and audio are still validation-grade. They do not yet carry enough mechanism-driven impact.

## Next Priority

1. V0.3.2e UI stylesheet consolidation.
   Merge the accumulated CSS patch layers into one formal UI system, remove obsolete panel/button definitions, and add an asset usage audit for every visible UI state.
2. V0.3.2f story point integration.
   Make story point art state-specific per scene pack, reduce generic floating badges, and add a near-player prompt that feels diegetic.
3. V0.3.3 map art polish.
   Improve Xuanyuan and Shennong tile edges, add 2-3 more low-contrast base variants per map, and separate base/decal/prop/event manifests.
4. V0.3.4 build and combat feel.
   Improve in-run build display, upgrade feedback, attack growth feedback, skill VFX scaling, and audio hooks.
5. V0.3.5 mobile UI.
   Keep mobile as a separate HUD/layout pass instead of force-scaling desktop UI.
