# 资源预算

单地图包目标：

- base tile：2-4 张，每张 45-90 KB。
- decal：4-8 张，每张 8-45 KB。
- 静态摆件：6-12 张，每张 5-35 KB。
- 动态摆件：1-3 组，每组 3-4 帧。
- 剧情点位：2-3 组，每组未触发、可触发、已记录三态。
- atmosphere：0-2 组，后续补充。

加载预算：

- 当前地图包：不超过 1.2 MB。
- 共用运行资源：不超过 2.5 MB。
- 首屏总加载：目标不超过 4 MB。
- 手机端超过 3 MB 预警。
- 总包超过 6 MB 必须复盘。

怪物和 Boss 预算：

- 普通小怪：每种 80-180 KB，小 WebP 图集。
- 精英怪：每种 180-300 KB，额外包含施法或狂暴帧。
- Boss：每个 400-800 KB，主体和循环特效拆分。
- 单地图怪物包：0.5-1 MB。

优化规则：

- 地面质感优先靠 tile 和静态 decal。
- 动画只给剧情点位、可交互物、强反馈特效。
- 不把概念图、预览图、raw PNG、中间抠图源图放进可玩包。
- 不在首屏一次性加载三张地图、全部怪物和 Boss。
